[sched_ext](https://github.com/sched-ext/scx) lets you run alternative CPU
schedulers on Linux. A CPU scheduler decides how processor time is shared
between applications. Different schedulers can change how your system responds
under load; a different scheduler is not automatically faster.

Keep the kernel's default scheduler as your baseline. Compare alternatives
with the same applications and workload, and keep the one that works better
on your hardware.

## How the tools fit together

- **Scheduler binaries** implement the scheduling behavior.
- **`scx.service`** starts the selected scheduler and supports starting it at boot.
- **`scxcli`** selects schedulers, manages their saved configuration and reports status.
- **`scxtui`** provides a terminal menu for the same switching workflow.

The upstream project develops sched_ext schedulers and tools. The
[Seafoam Labs fork](https://github.com/Seafoam-Labs/scx) provides Devario's
integration. Package contents vary by distribution: these guides cover the
`scxtui` / `scxcli` / `scx.service` workflow.
A scheduler that exits returns control to the kernel's own scheduler.

## Pearl desktop controls

Pearl also has graphical scheduler controls. Their profile files and helper
requirements belong to [Pearl's scheduling documentation](/pearl/docs/audio-power/#system-and-scheduling);
they are not interchangeable with the scxcli catalog. Use that guide for the
Pearl Settings interface and these guides for the terminal tools.

## Developer references

This page adapts the **sched_ext guide for Devario by [sir_lucjan](https://github.com/sirlucjan)**. It describes the
`scxtui` / `scxcli` / `scx.service` workflow in
[the current source](https://github.com/sched-ext/scx/tree/9344d26331bbdfbeec0e44d3cc444aed54b6a1a0).

[`v1.1.5-devario5`](https://github.com/Seafoam-Labs/scx/tree/v1.1.5-devario5).

- [scxtui reference](https://github.com/sched-ext/scx/blob/main/tools/scxtui/README.md): requirements, keyboard controls and interface behavior.
- [Catalog contract](https://github.com/sched-ext/scx/blob/main/services/CATALOG.md): schema, trust rules, status detection and client integration.
- [Scheduler descriptions](https://github.com/sched-ext/scx/blob/main/scheds/rust/README.md): individual schedulers and their intended workloads.
- [Upstream installation](https://github.com/sched-ext/scx/blob/main/INSTALL.md): source builds and other distributions. A tools-only build does not install scheduler binaries.
- [Seafoam Labs scx fork](https://github.com/Seafoam-Labs/scx): Devario integration and scheduler development.
- [Devario package recipes](https://github.com/Seafoam-Labs/devario-custom-packagbuilds): package contents and build configuration.
