Devario is a **free, open-source Linux desktop** built around Seafoam Labs
projects. The Community edition is an independent Linux distribution built
around the Aqueous Wayland compositor, Pearl desktop shell, and Shelly package
manager.
It can be built, installed, and used independently, without an organization
account or management service.

## What runs your desktop

<CardGrid>
  <Card title="Aqueous · windows and displays" icon="laptop">
    Handles windows, workspaces, displays, and input. Devario starts with
    floating windows; switch to tiling, scrolling, or other layouts when you
    want. See [Aqueous layouts](/aqueous/layouts/) and [display
    settings](/aqueous/outputs/).
  </Card>
  <Card title="Pearl · the desktop around them" icon="setting">
    Provides the bar, dock, launcher, notifications, control center, and
    settings. Pearl Greeter handles sign-in through greetd. See the [Pearl
    overview](/pearl/overview/) for desktop controls and customization.
  </Card>
  <Card title="Shelly · applications and updates" icon="puzzle">
    Installs, removes, and updates packages through a graphical interface and
    CLI. Devario uses Shelly's native RLPM backend. Start with [package
    management](/shelly-alpm/docs/packages/) or the [CLI
    reference](/shelly-alpm/docs/cli-reference/).
  </Card>
  <Card title="Pori · persistent disk mounts" icon="database">
    Sets up local disks to mount again after reboot using systemd mount units.
    Follow the [Pori user guide](/pori/user-guide/) to configure an additional
    drive.
  </Card>
</CardGrid>

## From live image to your own system

Boot the live image to try Aqueous and Pearl, then open **Install Devario**.
The Calamares installer guides you through language, keyboard, disk layout,
and a local user account. Installation copies the prepared live filesystem,
so the base desktop can be installed offline.

The image targets **x86-64-v3 hardware**. Live media can boot through BIOS or
UEFI, but installation requires **64-bit UEFI** and uses systemd-boot. Btrfs
is the default filesystem; ext4, XFS, and F2FS are also offered.
See [Setup and defaults](/devario/setup/) before installing.

## What else is included

| Part of the system       | Included software                                                                                            |
| ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| Kernel and boot          | Seafoam Labs' `linux-devario` kernel, Devario's dracut integration, systemd-boot, and a Plymouth boot splash |
| Everyday applications    | Firefox, Ghostty, and Pearl's Phyto file manager, Dome resource monitor, and Coral text editor               |
| Terminal                 | Fish, with a Devario Fastfetch summary in each new terminal                                                  |
| Connectivity             | NetworkManager, BlueZ for Bluetooth, and Bolt tools for Thunderbolt authorization                            |
| Sound and power          | PipeWire, WirePlumber, UPower, and power-profiles-daemon                                                     |
| Appearance               | Matugen color generation, Papirus icons, Vimix cursors, and Devario backgrounds                              |
| Credentials and firewall | GNOME Keyring, Seahorse, Polkit, and UFW                                                                     |
| Graphics                 | Mesa and Vulkan drivers, XWayland, and NVIDIA open kernel modules for supported GPUs                         |

The [ISO package list](https://github.com/Seafoam-Labs/devario-os/blob/main/iso/packages.x86_64)
is the full inventory. The [OS README](https://github.com/Seafoam-Labs/devario-os#readme)
explains how those packages are integrated; individual project guides may
describe features newer than the packages in a particular image.
