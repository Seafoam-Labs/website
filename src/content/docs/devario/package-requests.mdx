Missing packaged software, such as an application or library? Ask the Devario
team to add it to the repositories. You do not need to build it yourself.

## Check Shelly first

Open Shelly's **Package** page and search for the software. Turn off **Installed
Only** to include packages you have not installed.

If you find it, follow [Installing packages](/shelly-alpm/docs/packages/#installing-packages).
If Shelly reports a repository or download error, ask for help with that error
first. It does not mean the package is missing.

## Post your request

1. Join the [Seafoam Labs Fluxer community](https://fluxer.gg/vOjrMXcE), then
   open [devario-build-requests](https://web.fluxer.app/channels/1491098623729061280/1562659583711780864).
2. Check existing requests. If the software already has a thread, add any useful
   details there instead of starting another.
3. Select **New post** and use the application or library name as the title.
4. Add its official website or source repository link. You can also explain what
   you need it for. Select **Post** when you are ready.

For example, a request could use `PeaZip` as the title and this message:

```text
Project link: https://peazip.github.io/
Why I need it (optional): I use it to open and create archives.
```

Replace the example name and link with the software you want to request.

Mention a specific version, feature or application that needs a missing library
if relevant. An existing package link can help, but you do not need to work out
the dependencies yourself.

## Follow your thread

Check your thread for questions and updates from the maintainers. Once they
confirm the package is available, find it in Shelly and install it normally.
