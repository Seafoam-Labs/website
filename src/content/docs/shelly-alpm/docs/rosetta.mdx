Shelly Rosetta compares Shelly commands with Pacman commands for users familiar with either tool. Shelly commands appear first; the match column distinguishes equivalent operations from approximate counterparts.

Verified on **2026-10-03** for **Shelly 3.1.6** and **Pacman 7.1.0**, using the installed `man shelly`, `shelly utility --docs`, and `man pacman`. Transaction details were checked against Shelly's **v3.1.6** source; install, upgrade, removal, and synchronization commands were not executed.

**Coverage:** all 62 executable command paths documented by Shelly 3.1.6, all seven Pacman package-operation families (`D`, `F`, `Q`, `R`, `S`, `T`, `U`), and the principal query, transaction, and configuration controls. Examples cover distinct operations rather than every possible flag combination. Shortcode aliases, hidden compatibility commands, every print-format placeholder, every configuration-file directive, and the full CLIs of companion utilities are outside this table's scope.

- **`=`**: equivalent operation and package scope for the stated inputs; formatting and prompts can differ.
- **`≈`**: similar purpose, with a meaningful difference explained in the notes.
- **`—`**: no direct counterpart in the other tool's documented CLI.

Replace uppercase placeholders before running an example: `PKG` is an exact package name; `PKG…` means one or more selected names; `QUERY` is a search term; `REGEX` a regular expression; `GROUP` a package group; `REPO` a configured ALPM repository; `REMOTE` a Flatpak remote; `APP_ID` a Flatpak application/runtime ID; `APPIMAGE` a tracked AppImage name. `FILE` is an Arch package archive, `OLDER_FILE` an older archive, and `FILE.AppImage` an AppImage file. `PATH`/`DIR` are filesystem paths, `FILENAME` a filename, `URL` a download/server URL, `DB` a standalone repository database such as `./repo.db.tar.zst`, `KEY` a key identifier, and `SERVER` a keyserver URL. `DEP` is a dependency name/expression, `VERSION` a version, `ARCH` an architecture, `NAME` a manifest filename without `.toml`, and `CONFIG_FILE` a Pacman configuration file. Square brackets in explanations indicate optional arguments.

Shelly's `standard` backend covers ALPM packages, including configured third-party repositories. Removal equivalences assume ordinary, unheld ALPM packages. Shelly requests elevation when needed; privileged Pacman examples use `sudo`. Tables distinguish native Pacman commands from separate companion utilities.

## Common commands

| Shelly                                                          | Pacman                               | Match | Purpose / notes                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------------------------- | ------------------------------------ | :---: | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shelly install standard PKG`                                   | `sudo pacman -S PKG`                 |   ≈   | Install a repository package using stored databases. Shelly additionally offers optional dependencies for installation.                                                                                                                                                                                                                 |
| `shelly install standard PKG --needed`                          | `sudo pacman -S --needed PKG`        |   ≈   | Skip already current targets. | `shelly install standard PKG --upgrade`                         | `sudo pacman -Syu PKG`               |   ≈   | Refresh and upgrade before installing. Shelly separates the transactions and gates the upgrade on a newer-version pre-check; see the replacement-only limitation below.                                                                                                                                                                 |
| `shelly install standard FILE`                                  | `sudo pacman -U FILE`                |   ≈   | Install a local Arch package archive. Shelly uses a fixed signature setting; Pacman honors `LocalFileSigLevel`. [Implementation](https://github.com/Seafoam-Labs/Shelly-ALPM/blob/v3.1.6/Shelly.PackageManager/src/alpm/manager.zig#L1578).                                                                                             |
| `shelly install standard URL`                                   | `sudo pacman -U URL`                 |   ≈   | Install an Arch package archive from HTTP(S). Shelly downloads the archive to a temporary file; signature/download handling differs from Pacman's remote-package path.                                                                                                                                                                  |
| `shelly upgrade standard`                                       | `sudo pacman -Syu`                   |   ≈   | Full repository upgrade. Shelly forces database refresh and adds news, service-restart checks, and a cache-cleanup offer. [Implementation](https://github.com/Seafoam-Labs/Shelly-ALPM/blob/v3.1.6/Shelly.Cli.Zig/src/commands/upgrade.zig#L583).                                                                                       |
| `shelly list-updates standard`                                  | `pacman -Qu`                         |   ≈   | Shelly refreshes a separate user-owned database and excludes ignored packages/groups and repositories without upgrade usage. Pacman queries stored sync databases and can list updates marked `[ignored]`. [Implementation](https://github.com/Seafoam-Labs/Shelly-ALPM/blob/v3.1.6/Shelly.Cli.Zig/src/commands/list_updates.zig#L678). |
| `shelly list-updates all`                                       | `pacman -Qu`                         |   ≈   | Shelly checks repository, AUR, Flatpak, and AppImage updates; Pacman reports repository updates from stored databases. The standard-backend ignore-filter difference above still applies.                                                                                                                                               |
| `shelly sync`                                                   | `sudo pacman -Sy`                    |   =   | Refresh repository package databases without upgrading. See the partial-upgrade caution below.                                                                                                                                                                                                                                          |
| `shelly sync --force`                                           | `sudo pacman -Syy`                   |   =   | Force refresh even when databases appear current. | `shelly update standard PKG`                                    | `sudo pacman -Sy --needed PKG`       |   ≈   | Shelly refreshes and updates only newer versions of named installed packages. | `shelly downgrade PKG`                                          | `sudo pacman -U OLDER_FILE`          |   ≈   | Install an older version. Shelly finds/selects cached or archived versions; Pacman needs the archive path or URL.                                                                                                                                                                                                                       |
| `shelly search standard QUERY`                                  | `pacman -Ss QUERY`                   |   ≈   | Search repository names/descriptions. Shelly ranks text matches, paginates results, and hides ignored packages by default; Pacman accepts regular expressions.                                                                                                                                                                          |
| `shelly search standard QUERY --installed`                      | `pacman -Qs QUERY`                   |   ≈   | Search installed packages. The same matching, pagination, and hidden-package differences apply.                                                                                                                                                                                                                                         |
| `shelly search standard PKG --detail --show-hidden`             | `pacman -Si PKG`                     |   ≈   | Show repository metadata. Shelly selects one matching repository entry; Pacman can show matches from multiple repositories. `--show-hidden` includes ignored packages.                                                                                                                                                                  |
| `shelly search standard PKG --installed --detail --show-hidden` | `pacman -Qi PKG`                     |   ≈   | Show installed metadata. If PKG is absent locally, Shelly can fall back to repository metadata; Pacman reports an error.                                                                                                                                                                                                                |
| `shelly search standard`                                        | `pacman -Sl`                         |   ≈   | List available repository packages. Shelly paginates, hides ignored packages, and merges duplicate names across repositories.                                                                                                                                                                                                           |
| `shelly search standard GROUP --group --show-hidden`            | `pacman -Sg GROUP`                   |   ≈   | List a repository group's members. | `shelly search standard --repos`                                | —                                    |   —   | List configured repository names. Output formats differ.                                                                                                                                                                                                                                                    |
| `shelly list standard --explicitOnly`                           | `pacman -Qe`                         |   =   | List packages explicitly installed by the user.                                                                                                                                                                                                                                                                                         |
| `shelly list standard --dependencyOnly`                         | `pacman -Qd`                         |   =   | List packages installed as dependencies.                                                                                                                                                                                                                                                                                                |

| `shelly mark dependency PKG`                                    | `sudo pacman -D --asdeps PKG`        |   =   | Change the installed package's reason to dependency without reinstalling.                                                                                                                                                                                                                                                               |
| `shelly remove standard PKG --no-cascade`                       | `sudo pacman -R PKG`                 |   =   | Remove an ALPM package while keeping newly unneeded dependencies and normal `.pacsave` handling.                                                                                                                                                                                                                                        |

| `shelly remove standard PKG --opt-deps`                         | `sudo pacman -Rns PKG`               |   ≈   | Shelly additionally selects optional dependencies for removal. Review the plan: some may still be optional for another application.                                                                                                                                                                                                     |
| `shelly remove standard PKG --remove-config`                    | `sudo pacman -Rns PKG`               |   ≈   | Shelly additionally removes the package-named directory under the user's configuration directory. Pacman's `-n` suppresses `.pacsave`; it does not delete application-created home settings.                                                                                                                                            |
| `shelly remove aur PKG`                                         | `sudo pacman -R PKG`                 |   ≈   | Remove an installed AUR package; Shelly additionally clears its build-cache/VCS tracking state. Unlike `remove standard`, dependency cleanup is not enabled by default here.                                                                                                                                                            |
| `shelly purify standard --orphans --dry-run`                    | `pacman -Qdt`                        |   ≈   | Identify unneeded dependency-installed packages. Shelly's preview also includes corrupted cached archives.                                                                                                                                                                                                                              |

| `shelly purify standard --cache 0`                              | `sudo pacman -Scc`                   |   ≈   | Shelly removes recognized cached package archives/signatures; Pacman clears all package-cache files and can also remove unused sync databases.                                                                                                                                                                                          |
| —                                                               | `sudo pacman -Sw PKG`                |   —   | Download repository packages and dependencies without installing. No dedicated documented Shelly counterpart.                                                                                                                                                                                                                           |
| —                                                               | `pacman -Ql PKG`                     |   —   | List files owned by an installed package.                                                                                                                                                                                                                                                                                               |

| —                                                               | `pacman -Qk PKG` / `pacman -Qkk PKG` |   —   | Check installed files for presence / additional metadata. Shelly's `purify` checks cached archives instead.                                                                                                                                                                                                                             |

## Notes and sources

**Partial upgrades:** prefer `shelly upgrade standard` or `sudo pacman -Syu` for routine upgrades. Refreshing system databases without completing a full upgrade, then installing/updating selected packages, can leave incompatible package versions. Arch Linux does not support partial upgrades. [ArchWiki: System maintenance](https://wiki.archlinux.org/title/System_maintenance#Partial_upgrades_are_unsupported).

**Replacement-only limitation in Shelly 3.1.6:** the standard-upgrade path returns early when its same-name newer-version pre-check is empty; `install standard --upgrade` also gates its upgrade on that pre-check. **Inference:** repository replacements alone may be skipped, while Pacman's full-upgrade transaction processes replacements. This is a source-based qualification; no upgrade transaction was executed to test it. [Upgrade pre-check](https://github.com/Seafoam-Labs/Shelly-ALPM/blob/v3.1.6/Shelly.Cli.Zig/src/commands/upgrade.zig#L603), [installation pre-check](https://github.com/Seafoam-Labs/Shelly-ALPM/blob/v3.1.6/Shelly.Cli.Zig/src/commands/install.zig#L535).

**Short options differ between tools.** For example, `shelly -Rs` means `shelly remove standard`, while `pacman -Rs` means remove a package and its unneeded dependencies while retaining normal backup handling. The table uses Shelly's long commands to make the operation explicit. [Shelly CLI reference](https://www.seafoam-labs.org/shelly-alpm/docs/cli-reference/).

The installed-package, explicit-package, and dependency-package listings were checked directly: Shelly and Pacman returned identical package names and versions in all three cases. Other mappings are based on the installed manuals, generated CLI documentation, and versioned source, rather than executing transactions. Pacman's option definitions are also available in the official [pacman(8) manual](https://pacman.archlinux.page/pacman.8.html).

This comparison contains 166 rows of examples and variants. Coverage was checked against all 62 executable command paths in Shelly's generated CLI reference and all seven Pacman package-operation families. The scope exclusions above still apply.
