Shelly Rosetta is a reference for pacman commands and their equivalent Shelly commands. It is intended to help users who are familiar with pacman to transition to Shelly.

## Install or update

| pacman                | shelly shortcode/longcode                                             | Description                                                   |
| --------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------- |
| `pacman -S package`   | `shelly -Is package`<br/>`shelly install standard package`            | (Re)Install a package                                         |
| `pacman -Syu`         | `shelly -Us`<br/>`shelly upgrade standard`                            | Update packages from configured repos                         |
| `pacman -Syu package` | `shelly -Isu package`<br/>`shelly install standard --upgrade package` | Install a package and do a system update                      |
| `n/a`                 | `shelly -Px`<br/>`shelly list-updates all`                            | Show available updates                                        |
| `pacman -U URL`       | `shelly -Is URL`<br/>`shelly install standard URL`                    | Download and install a .pkg.tar.zst package from the internet |

## Search or information

| pacman/related        | shelly shortcode/longcode                                                        | Description                                                                                                                                              |
| --------------------- | -------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pacman -Ss <string>` | `shelly -Ssv package`<br/>`shelly search standard --available <string>`<br/>     | Search configured repos for a package containing \<string\> in the name, description, or group                                                           |
| `pacman -Si package`  | `shelly -Ssvd package`<br/>`shelly search standard --available --detail package` | Get detailed information about a package in configured repos                                                                                             |
| `pacman -Qs <string>` | `shelly -Ssi <string>`<br/>`shelly search standard --installed <string>`         | Search locally installed package names                                                                                                                   |
| `pacman -Qi package`  | `shelly -Ssd package`<br/>`shelly search standard --installed --detail package`  | Get detailed information for a locally installed package                                                                                                 |
| `yay -Ss <string>`    | `shelly -Ssav <string>`                                                          | Search for a package in configured repos and the AUR                                                                                                     |
| `yay -Si package`     | `shelly -Sad package`<br/>`shelly search aur --detail package`                   | Get detailed information about a package in configured repos or the AUR                                                                                  |
| `pacman -Qm`          | `shelly -La`<br/>`shelly list aur`                                               | List packages installed from the AUR.                                                                                                                    |
| `pacman -Qe package`  | `shelly -Sse`<br/>`shelly search standard --explicit`                            | List all explicitly installed packages. This is primarily used for package list backup purposes like with `pacman -Qqe`, but `shelly backup` covers that |
| `yay -Pw`             | `shelly -N`<br/>`shelly news`                                                    | Find unread Arch Linux news                                                                                                                              |

## Remove

| pacman                          | shelly shortcode/longcode                                                           | Description                                                                                                                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pacman -R package`             | `shelly -Rs --no-cascade package`<br/>`shelly remove standard --no-cascade package` | Remove a single package, leaving all of its dependencies installed                                                                                                            |
| `pacman -Rs package`            | `shelly -Rs package`<br/>`shelly remove standard package`                           | Remove a package and its dependencies which are not required by any other installed package                                                                                   |
| n/a                             | `shelly -Rso package`<br/>`shelly remove standard --opt-deps`                       | Remove a package, its dependencies which are not required by any other installed package, and also optional dependencies installed with package                               |
| `pacman -Rsc package`           | `shelly -Rsi package`<br/>`shelly remove standard --ripple`                         | Remove a package, its dependencies and all the packages that depend on the target package. <Badge text="Be very careful running this" size="small" variant="danger" />        |
| `pacman -Rdd package`           | `shelly -Rsf package`<br/>`shelly remove standard --force package`                  | Remove a package, skipping any dependency checks. <Badge text="This can break your system. Only run if advanced user or directed by support" size="small" variant="danger" /> |
| `pacman -Sc`                    | `shelly -Zsc [<number>]`<br/>`shelly purify standard --cache [<number>]`            | Clean the local package cache, keeping \<number\> versions. 3 versions are kept if no number specified.                                                                       |
| `pacman -Qdtq \| pacman -Rns -` | `shelly -Zso`<br/>`shelly purify standard --orphans`                                | Remove packages that were installed as a dependency and are no longer required by any package, aka orphans                                                                    |

## Downgrading

| pacman/related      | shelly shortcode/longcode                                    | Description                                                                                                                            |
| ------------------- | ------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `downgrade package` | `shelly -Di package`<br/>`shelly downgrade --ignore package` | Revert a package you have installed to an earlier cached version or cachy repo version if available and also add it to the ignore list |
