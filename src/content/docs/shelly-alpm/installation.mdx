Shelly is a native package manager for Arch Linux. It provides both a GTK4
application and command-line tools that interface directly with `libalpm`.

## Requirements

Shelly runs on Arch Linux and Arch-based distributions. To build it from source,
you need:

- Zig 0.16.0
- `libalpm`, provided by `pacman`

## Arch Linux

Prebuilt Shelly packages are available from CachyOS and the AUR. The package
includes the graphical interface and command-line tools.

<Card title="CachyOS / pacman (Recommended)" icon="download">

### Build from source

Clone the repository and use its git `PKGBUILD`:

```sh
git clone https://github.com/Seafoam-Labs/Shelly-ALPM.git
cd Shelly-ALPM
cp PKGBUILD-git PKGBUILD
makepkg -si
```

## Starting Shelly

Launch the graphical application with:

```sh
shelly-ui
```

For terminal-based package management, run `shelly`. Shelly creates its default
CLI configuration at `~/.config/shelly/config.json` on first use.

<Aside type="note" title="Optional Flatpak support">
  Install `flatpak` and `shelly-flatpak-backend` to manage Flatpak applications
  from Shelly. The backend is loaded only when performing a Flatpak operation,
  so it is not required for a base Shelly installation.
</Aside>
